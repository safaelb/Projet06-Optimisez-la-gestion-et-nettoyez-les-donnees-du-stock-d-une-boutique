## 🎯 Contexte
Mission pour un manager de la grande distribution : nettoyer les données du stock, résoudre les incohérences et préparer les données pour l'analyse.

## 📚 Compétences développées
- Effectuer des analyses univariées et multivariées des données pré-traitées
- Explorer et analyser des données avec Python (Pandas, NumPy, Seaborn)
- Traiter et nettoyer des données en définissant des règles de gestion des incohérences
- Vérifier la cohérence et la fiabilité des données préparées

## 🧠 Ce que j'ai appris
Ce projet m'a permis de prendre en main Python pour la data analyse : nettoyage de données réelles, détection de doublons, gestion des valeurs manquantes et premières analyses statistiques descriptives. J'ai découvert la puissance des bibliothèques Pandas et Seaborn pour l'exploration visuelle.

## 🗂️ Livrables
- Notebook Python documenté (nettoyage + analyse)
- Rapport d'analyse exploratoire (statistiques descriptives)
- Visualisations univariées et multivariées
